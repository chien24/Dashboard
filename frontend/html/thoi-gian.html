Đạo Vận Chi Lượng

Chọn một hoặc nhiều file Excel (.xlsx) cùng cấu trúc. Cộng cột F (dạng 1h33m40s, 2m9s, 10s) giống công thức Excel, chia theo thiết bị ở cột A. File chỉ đọc trên máy, không gửi lên server và không lưu lại: tải lại trang (F5) là mất, muốn xem lại thì chọn file lần nữa.

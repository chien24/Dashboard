# Đổi giao diện sáng / tối

Còn gọi là: dark mode, chế độ tối, nền đen, light mode, "đổi màu nền".

**Kết quả:** cả trang web đổi sang nền tối (hoặc nền sáng). Lựa chọn được nhớ cho các lần mở sau trên trình duyệt đó.
**Cần có trước:** không cần đăng nhập.

## Các bước đổi giao diện sáng / tối

1. Nhìn nút tròn ở góc trên bên phải, trên thanh màu đỏ, sát mép phải.
2. Nút hình mặt trăng: đang ở chế độ sáng. Rê chuột lên thấy chữ "Chuyển sang chế độ tối".
3. Nút hình mặt trời: đang ở chế độ tối. Rê chuột lên thấy chữ "Chuyển sang chế độ sáng".
4. Bấm nút. Giao diện đổi ngay, nút đổi hình.

## Nếu đổi giao diện sáng / tối không như mong muốn

| Hiện tượng | Nguyên nhân | Cách xử lý |
| --- | --- | --- |
| Lần đầu mở web đã ở chế độ tối | Chưa chọn lần nào thì trang web theo cài đặt sáng/tối của Windows | Bấm nút để chọn; từ đó trang nhớ lựa chọn |
| Mở lại web thì về chế độ cũ | Trình duyệt chặn lưu dữ liệu trang web, hoặc dùng cửa sổ ẩn danh | Bấm lại nút mỗi lần mở |

## Lưu ý khi đổi giao diện sáng / tối

- Chân trang và trang "Thiên Đạo phong ấn" luôn nền tối ở cả hai chế độ.
- Lựa chọn chỉ lưu trên trình duyệt đang dùng, không áp dụng cho máy khác.
